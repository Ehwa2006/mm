Kebijakan Privasi

Kebijakan ini menjelaskan data apa yang diproses saat Anda menggunakan situs Hitung Gaji Korea ("situs") di hitunggajikorea.com.

1. Data yang Anda masukkan ke kalkulator

Semua perhitungan dilakukan di browser Anda. Angka yang Anda masukkan (gaji, jam kerja, tanggal, dan sebagainya) tidak dikirim ke server kami dan tidak disimpan. Situs ini tidak memiliki formulir pendaftaran atau akun pengguna.

2. Hosting

Situs ini di-hosting di GitHub Pages. Seperti server web lain, GitHub dapat mencatat data teknis seperti alamat IP untuk keamanan dan operasional. Lihat pernyataan privasi GitHub.

3. Iklan Google AdSense dan cookie

  • Situs ini menampilkan iklan dari Google AdSense untuk membiayai operasional.
  • Google dan mitranya menggunakan cookie untuk menampilkan iklan berdasarkan kunjungan Anda ke situs ini dan situs lain.
  • Cookie iklan Google memungkinkan Google dan mitranya menayangkan iklan berdasarkan kunjungan Anda.
  • Anda dapat menonaktifkan iklan yang dipersonalisasi di Setelan Iklan Google, atau menonaktifkan cookie pihak ketiga di aboutads.info.
  • Informasi lebih lanjut: Cara Google menggunakan data dari situs yang memakai layanannya.

4. Persetujuan pengguna di Eropa

Pengunjung dari Wilayah Ekonomi Eropa (EEA), Inggris, dan Swiss akan melihat pesan persetujuan dari platform pengelolaan persetujuan (CMP) Google yang tersertifikasi. Anda dapat menyetujui, menolak, atau mengatur pilihan cookie di sana.

5. Anak-anak

Situs ini ditujukan untuk pekerja dewasa dan tidak sengaja mengumpulkan data dari anak-anak.

6. Perubahan kebijakan

Kebijakan ini dapat diperbarui. Tanggal perubahan terakhir tercantum di bagian atas halaman.

7. Kontak

Pertanyaan tentang kebijakan ini dapat dikirim melalui halaman kontak.

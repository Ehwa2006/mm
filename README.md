# Hitung Gaji Korea

한국에서 일하는 인도네시아 노동자(EPS/E-9)와 한국 취업을 준비하는 인도네시아인을 위한 인도네시아어 급여 계산기 사이트예요. 검색 유입을 받아 광고(Google AdSense)로 수익을 내는 것이 목표예요.

- 월 실수령액 계산기: 연장·야간·휴일수당, 4대보험, 소득세, 기숙사비 공제, 루피아 환산 (`/kalkulator-gaji/`)
- 퇴직금 계산기: 출국만기보험 예상액과 사업주가 줘야 하는 차액 (`/pesangon/`)
- 국민연금 반환일시금 계산기 (`/pengembalian-pensiun/`)
- 주휴수당 계산기 (`/uang-libur-mingguan/`)
- 연차·연차수당 계산기 (`/cuti-tahunan/`)
- E-9 사업장 변경 규칙 안내 (`/pindah-kerja/`)
- 연도별 최저임금 (`/upah-minimum/`)
- 실업급여 계산기, E-9 임의가입 조건 (`/tunjangan-pengangguran/`)
- 산재보험 권리·신청 방법 (`/kecelakaan-kerja/`)
- 건강보험 공제·혜택·출국 시 정산 (`/asuransi-kesehatan/`)
- 외국인근로자 전용보험 4종 (`/asuransi-khusus-eps/`)
- 숙식비 공제 한도 계산기 (`/potongan-asrama/`)
- 임금체불 신고·간이대지급금 (`/gaji-tidak-dibayar/`)
- 성실근로자 재입국 특례 (`/pekerja-setia/`)
- 저축액 계산기 (`/kalkulator-tabungan/`)
- 인도네시아어 상담 가능 전화번호 (`/nomor-penting/`)
- EPS-TOPIK부터 입국·취업까지 절차 (`/alur-eps/`)
- 사이트 소개·연락처 (`/tentang/`)

서버 없이 동작하는 정적 사이트라서 호스팅 비용이 없어요. 계산은 모두 브라우저에서 이루어져요.

## 이 분야를 고른 이유

| 후보 | 경쟁 | 광고 수익화 | 판단 |
| --- | --- | --- | --- |
| 한국어 급여 계산기 (이전 프로젝트 "월급계산소") | 매우 치열 (네이버 기본 계산기, 취업 포털, 계산기 사이트 다수) | 가능 | 폐기 |
| 영어 외국인 급여 계산기 | 치열 (전용 도구 7개 이상) | 가능 | 제외 |
| 네팔어·크메르어 | 거의 없음 | AdSense 미지원 언어 | 제외 |
| **인도네시아어** | 낮음 (기사·틱톡 위주, 전용 계산기 1~2개) | AdSense 지원 | **선택** |

## 운영 규칙

- **경쟁 판단 기준**: 대상 언어로 핵심 키워드를 검색했을 때 첫 페이지에 전용 계산기·도구 사이트가 3개 이상이면 "경쟁이 매우 치열"로 본다.
- 진행 중인 프로젝트가 이 기준에 걸리면 기존 프로젝트를 폐기하고, 경쟁이 낮고 AdSense 지원 언어인 다른 분야로 새로 시작한다.
- 계정 가입, 본인인증, 세금 정보, 결제, 계좌 등록은 사용자가 한다. 나머지는 코드로 처리한다.

## 구조

```
src/assets/calc.js   계산 로직 (브라우저와 Node 테스트에서 함께 사용)
src/pages/*.html     페이지 본문 (인도네시아어)
build.py             공통 레이아웃을 입혀 docs/ 에 사이트를 생성
site.json            도메인, AdSense ID, Search Console 소유확인 코드
docs/                배포용 결과물 (GitHub Pages가 이 폴더를 서비스)
tests/               계산 로직 테스트
```

```
npm run build   # docs/ 재생성
npm test        # 계산 로직 테스트
```

`src/` 나 `site.json` 을 고친 뒤에는 `npm run build` 를 실행해서 `docs/` 까지 함께 커밋해야 해요.

## 수익화 순서

사용자가 직접 해야 하는 일은 ☐ 로 표시했어요.

1. ☐ 저장소를 공개(public)로 전환하고 Settings → Pages 에서 Source 를 기본 브랜치의 `/docs` 로 지정 (비공개 저장소는 유료 플랜에서만 Pages 사용 가능)
2. ☐ 도메인 구입 (연 1~2만 원). AdSense 는 `github.io` 주소를 승인하지 않아요
3. ☐ 도메인 업체 DNS 에 GitHub Pages 레코드 입력: A 레코드 `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` / `www` CNAME `ehwa2006.github.io`
4. `site.json` 의 `custom_domain` 설정 후 빌드
5. ☐ Google Search Console 가입 후 "HTML 태그" 소유확인 코드 발급 (인도네시아 검색은 대부분 구글이라 네이버 등록은 필요 없어요)
6. `site.json` 에 소유확인 코드 입력 후 빌드, `sitemap.xml` 제출
7. ☐ AdSense 가입, 본인인증, 게시자 ID 발급
8. `site.json` 의 `adsense_client` 설정 후 빌드
9. ☐ AdSense 승인 후 지급 계좌와 세금 정보 등록. 누적 100달러부터 지급

## 현실적인 기대치

- 검색엔진에 색인되고 순위가 오르기까지 보통 1~3개월 걸려요.
- 한국에 있는 방문자는 광고 단가가 괜찮지만, 인도네시아 현지 방문자는 단가가 낮아요(방문 1,000회당 수백 원~천 원대).
- 경쟁이 낮은 대신 검색량도 한국어 급여 계산기보다 적어요. 페이지를 계속 늘려서 롱테일 키워드를 잡는 전략이에요.
